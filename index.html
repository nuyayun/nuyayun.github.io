Profil

Lulusan Sarjana Komputer yang senang mengubah ide menjadi alat belajar dan aplikasi yang benar-benar dipakai.

Saya Khairul Anwar, S.Kom., pengembang aplikasi dengan fokus pada web, jaringan komputer, dan teknologi pembelajaran. Saya mengerjakan proyek dari analisis kebutuhan sampai aplikasi siap dipakai.

Beberapa karya saya adalah simulator topologi jaringan dan laboratorium virtual berbasis web untuk siswa SMK. Saya percaya praktik langsung lewat layar lebih cepat membangun pemahaman daripada teori saja.

Di luar proyek utama, saya rutin membuat eksperimen kecil untuk menguji teknologi baru dan mengumpulkannya di Technology Hub.
